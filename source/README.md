# source/

Raw and working source text kept for reference — OCR/scraped originals and intermediate,
chapter-split drafts for a few of the Purāṇas — not `\input` by the compiled book. The
typeset, `\input`-ready versions live under [`rama-charitam/`](../rama-charitam/README.md)
and [`katha/`](../katha/README.md).

| Path | Contents |
|---|---|
| `padma-puranam/chaps-orig.tex` | Original OCR/scraped text before editing. |
| `padma-puranam/chaps.tex` | Chapter-split working draft. |
| `padma-puranam/chaps-verse-patterns.txt` | Per-verse metrical (chandas) analysis. |
| `skanda-puranam/chaps-orig.tex` | Original OCR/scraped text before editing. |
| `skanda-puranam/chaps-edited.tex` | Edited working draft. |
| `vishnudharmottara-puranam/orig-text.txt` | Original scraped plain-text source. |
