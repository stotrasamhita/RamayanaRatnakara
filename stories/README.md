## Stories

This folder should ideally mirror the tree structure of the `mulam` folder above (i.e. of
[`rama-charitam/`](../rama-charitam/README.md) and [`katha/`](../katha/README.md)). It should
contain the English(!) translations/summaries of all the `mulams` in the other folder.

**Status:** currently just a scaffold — `ramayana-ratnakara-stories.tex` (master file),
`stories-cover.tex`, and `shloka.sty` exist, but no per-story content files have been added yet.
